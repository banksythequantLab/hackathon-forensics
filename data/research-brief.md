# Hackathon Spy/Auditor — Research Brief
**Focus:** Completed AI/ML Devpost (and similar) hackathons, 2024–2026  
**Purpose:** Design a product that audits finished hackathons and compares them  
**Target context:** Nebius × NVIDIA Global AI Hackathon (deadline Oct 30 2026 PDT)  
**Research date:** 2026-09-16  
**Method note:** Participant/prize figures from Devpost event pages. Archetype %s are **rough estimates** from winners + featured/gallery samples (not full corpus counts). Marked EST. where estimated.

## 4. Patterns for Nebius × NVIDIA — overdone vs white space

**Nebius tracks reminder:** Coding & Agentic Engineering · Best Apps & Agents · Personal AI · Physical AI  
**Required:** Nebius Token Factory or AI Cloud + ≥1 NVIDIA open-source model (Nemotron / GR00T / Cosmos / Sonic etc.)

### Overdone (high competition / low differentiation if generic)
1. Another chat-first “personal assistant” without durable memory, tools, or privacy story  
2. Generic RAG over PDFs / “legal contract chatbot”  
3. Meal planner / fitness coach clones  
4. Fake-news detector  
5. Symptom checker / “AI doctor” without clinical rigor or novel data loop  
6. Marketing image/video content generator  
7. JARVIS clone that only demos vision Q&A  

### White-space opportunities (winners rarely occupied; fit Nebius)

1. **Hackathon Spy/Auditor (meta-product)** — Cross-event gallery mining, archetype clustering, “what won vs what’s tired,” citeable comparisons. Essentially **zero** observed winners in this niche. Perfect narrative for Apps & Agents *and* for judging “Quality of Idea.”  
2. **Physical AI with GR00T/Cosmos/Sonic + Nebius Serverless Jobs** — OpenAI showed robotics/hardware **wins grand prizes** when incentivized; most other galleries are pure SaaS. Simulation, synthetic data, policy eval on Nebius Jobs = track-aligned and scarce.  
3. **True Personal AI: persistent memory + user-controlled data + skills/tools** — Memory Palace proved judges love offline/private caregiving; Nebius Personal AI track *asks* for this (NemoClaw, OpenShell, Hermes Agent). Most “personal AI” entries are chat UIs without real memory architecture.  
4. **Coding agents that write/run/test in Token Factory Sandboxes** — RepoPilot-style exists but is uncommon; Coding track is explicit. Differentiate with closed-loop eval, not “chat that suggests code.”  
5. **Vertical ops automation (Klinva/CallVance pattern)** — One industry, workflow depth, measurable ROI > flashy general AI. Underrepresented relative to win rate.  
6. **Model/agent evaluation harnesses (ModelMash+) ** — Builder tooling for Nemotron Nano vs Super vs Ultra routing, cost/latency/quality dashboards on Nebius endpoints.  
7. **Hybrid edge + cloud Personal/Physical AI** — On-device sensing + Nebius for heavy reasoning (Chrome winners proved privacy/offline wins; few stitch edge + GPU cloud well).  
8. **Multi-hackathon intelligence for organizers/sponsors** — Sponsor ROI, track saturation analytics, duplicate-idea detection across Devpost galleries — adjacent white space to Spy/Auditor, B2B angle.

### Stand-out formula observed across events
Winners that weren’t “another chatbot” tended to combine **≥2 of:**
- Narrow real user + measurable outcome  
- Non-chat primary UX (timeline, CRM, robot, browser automation, scent hardware)  
- Strong use of *sponsor-required* stack (not optional garnish)  
- Demo video that proves the hard part works (robot moves, offline works, keys rotate, video actually edits)

## 5. Surprising findings

1. **World’s largest AI hackathon grand prize was video editing infrastructure, not an agent.** Tailored Labs beat 128k-scale field with NL → production edit pipeline.  
2. **3rd place was API-key security (KeyHaven)** — “boring” infra can podium when pain is universal.  
3. **When categories force hardware/local/fine-tune, winners look nothing like typical Devpost AI galleries.** OpenAI’s top set is robots, scent printers, Steam Decks, offline memory, Dota agents — not RAG bots.  
4. **Accessibility is a systematic Chrome winner pattern** (2025 Nutshell/AAC; 2024 Mochi/Orma-style). Judges overweight real user need + private on-device.  
5. **Vertical niche SaaS (cleaning CRM) outranked many flashy GenAI demos** in Bolt top 10.  
6. **Participant scale ≠ idea diversity:** Bolt’s top 10 still clusters around consumer AI + SaaS; true weirdness needed explicit prize categories.  
7. **NVIDIA GR00T already appeared in a winning OpenAI project (RoboChef)** — Nebius Physical AI entrants are not inventing the narrative; they’re competing in a lane that’s *proven* to win when executed.  
8. **Meta tools that analyze other hackathons appear absent** from sampled galleries — strong originality claim for Hackathon Spy/Auditor if execution is deep (not a thin scraper UI).

## 7. Implications for the product (research only — not a one-pager)

A credible **Hackathon Spy/Auditor** should, at minimum, ingest completed Devpost galleries (winners + featured), normalize project titles/descriptions, cluster into the archetype taxonomy above, score “tiredness” vs “white space” per upcoming event tracks, and produce citeable cross-hackathon comparisons like this brief. Highest differentiation vs existing winners: **comparative meta-analytics + track-aware white-space recommendations**, not live stalking of a single ongoing hackathon.

**Data gaps / caveats:** Full submission corpuses not scraped; archetype %s are EST. from winners/featured samples. Some “Winner” badges on galleries don’t specify place. Gemini 3 and other 2026 events need status check before inclusion as “completed.”
